### 把刷到的 AI 视频，从“看起来很厉害”变成真正能理解、能复用、能继续创作的个人审美资产

一个面向 AI 视频创作者的 Chrome 扩展：在 X / Twitter 上一键收藏视频，自动拆解视觉风格、镜头语言、节奏、声音与提示词，逐步建立属于你的审美库，并从灵感直接走到分镜、画面和成片。

## 为什么做 Style Lens

做 AI 视频时，我们经常在 X / Twitter 上看到很惊艳的作品。通常的做法是点赞、收藏、截几张图，或者复制作者公开的提示词。但收藏越来越多之后，真正的问题并没有解决：

- 你喜欢的到底是画面质感、配色、光线，还是节奏和运镜？
- 一条十几秒的视频用了多少个镜头，每一镜为什么有效？
- 作者的提示词为什么能得到这种效果，哪些部分可以迁移到自己的题材？
- 收藏了几十条作品之后，能不能看出自己稳定的审美偏好？
- 能不能不照搬原作，而是把学到的风格手法用于一个全新的主题？

Style Lens 希望补上“收藏”和“创作”之间缺失的那一层。

它不只是把视频交给模型总结，而是把一条灵感逐步转化为结构化风格档案、镜头证据、可复用提示词和创作方案。随着收藏增加，它还会将单条视频的观察汇总成你的审美报告、风格分组和风格卡。最终，你可以从任意一条收藏、一组相近风格或一张风格卡出发，设计自己的新视频。

## 它能做什么

### 1. 在浏览视频时直接收藏和拆解

打开一条 X / Twitter 视频帖，扩展会在 Chrome 侧边栏识别当前内容。你可以选择：

- **收藏风格**：快速理解作品的核心视觉语言，适合日常积累灵感。
- **完整拆解**：进一步分析每个镜头的时间、画面、动作、运镜、转场和声音，适合认真学习或复刻制作流程。

任务在后台执行，完成后会发送浏览器通知。你可以继续浏览其他内容，不必一直停留在当前页面。

### 2. 把零散收藏变成个人审美库

每条收藏不再只是一个链接，而是一份可检索的风格档案，包含：

- 视频摘要与创意概念
- 媒介质感、色彩、光影和画面构图
- 景别、运镜、节奏与转场规律
- 台词、音乐、音效和卡点方式
- 适合复用的中英文提示词
- 作者是否公开提示词及相关说明
- 你亲自勾选的“喜欢点”

审美库会统计你经常收藏的风格维度，让“我觉得好看”逐渐变成一套可以说清楚的视觉偏好。

### 3. 用关键帧理解镜头，而不只依赖文字

文字只能描述“像什么”，关键帧才真正保留“具体长什么样”。Style Lens 会在浏览器本地扫描视频：

- 按镜头提取首帧、尾帧和明显变化的画面
- 校准镜头切点和快剪节奏
- 将关键帧与该镜头的提示词放在一起查看
- 导出原视频、关键帧、分镜提示词和使用说明

这些素材可以继续用于即梦、可灵等工具的图生视频、首尾帧生成或风格参考。关键帧提取在本地完成，不消耗模型额度。

### 4. 看见自己长期形成的审美

当收藏积累到一定数量后，Style Lens 可以把数据整理成一份“视频美学杂志式”的审美报告：

- 哪些视觉风格最常出现
- 你主动标记的偏好与模型标签是否一致
- 哪些收藏最能代表某种审美倾向
- 你的节奏、光影、构图和叙事偏好是什么
- 下一条视频可以尝试怎样的新主题

它还可以自动比较收藏之间的相似性，生成风格分组。每个分组都能进一步提炼成一张长期复用的风格卡。

### 5. 从参考作品出发，设计完全不同的新内容

选择一条收藏、一组风格或一张风格卡，输入你自己的主题，扩展会保留参考作品的风格手法，但重新设计内容，输出完整分镜方案：

- 视频主题、时长和画幅
- 每一镜的起止时间
- 画面主体、场景和构图
- 动作、运镜和转场
- 音乐、音效和节奏安排
- 每一镜可直接使用的生成提示词

你还可以上传人物、产品或角色参考图，让分镜中的主体描述自动跟随参考图调整，保持角色外观和整体调性一致。

### 6. 从分镜继续生成画面和视频

分镜不是终点。你可以直接在扩展里：

- 为单个镜头生成画面
- 一键补齐全部分镜画面
- 对不满意的局部提出修改要求
- 在多个版本之间切换和回退
- 自动检查画面是否符合镜头要求
- 使用分镜图作为首帧，逐镜生成视频片段
- 将全部分镜图作为参考，一次生成带音乐音效的整片
- 修改或延长已经生成的视频
- 预览并导出无声成片、分镜素材包和剪辑表

生成任务会显示预算提示与进度，并允许设置每条视频的预算上限，减少失控消费的风险。

## 适合谁使用

- **AI 视频创作者**：系统研究优秀作品，并将风格转化为自己的创作方案。
- **导演与分镜师**：快速分析镜头结构、切点、构图和节奏，并生成分镜初稿。
- **设计师与广告创意人员**：建立视觉参考库，沉淀产品、品牌和视觉风格方向。
- **提示词学习者**：对照原片、关键帧和中英文提示词，理解提示词如何作用于画面。
- **内容研究者**：从大量收藏中观察题材、媒介、剪辑和叙事偏好的变化。

## 支持的模型与服务

Style Lens 不绑定单一模型。你可以选择一个服务完成全部工作，也可以按任务组合不同服务。

| 服务 | 主要用途 | 说明 |
| --- | --- | --- |
| Atlas Cloud | 视频拆解、分镜、生图、整片视频 | 一个 Key 覆盖主要流程，适合快速开始 |
| Google Gemini | 视频理解、提示词与图像生成 | 使用 Google 官方接口 |
| 米醋 API | Gemini 兼容接入 | 作为可选第三方接口来源 |
| 阿里云百炼 / 通义千问 | 多模态视频分析与文本生成 | 支持不同地域及业务空间服务地址 |
| 火山方舟 / Seedance | 逐镜视频与整片视频生成 | 支持多种 Seedance 模型和分辨率 |

实际可用模型、地区限制和价格取决于你的服务商账号。模型调用会产生第三方费用；扩展内的费用显示只是估算，最终账单以服务商为准。

## 安装方式

### 从 Release 安装

1. 前往 [Releases](https://github.com/cjx200110-lgtm/style-lens/releases/latest) 下载 `style-lens-v0.19.0.zip`。
2. 将压缩包完整解压到一个固定目录。
3. 在 Chrome 地址栏打开 `chrome://extensions/`。
4. 打开页面右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择刚才解压的目录。
6. 点击扩展图标进入设置页，配置所需的模型服务与 API Key。

### 从源码安装

```bash
git clone https://github.com/cjx200110-lgtm/style-lens.git
```

随后在 `chrome://extensions/` 中加载克隆得到的 `style-lens` 目录即可。本项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖，也不需要构建。

**运行要求：Chrome 114 或更高版本。**

## 第一次使用

如果你希望最少配置，可以在设置页选择 Atlas Cloud 方案并填写一个 Key。扩展会根据视频拆解、分镜、生图和视频生成等不同任务自动选择相应模型。

如果你希望自己组合服务，可以切换到自定义方案，分别配置：

- Gemini、米醋 API 或通义千问，用于视频分析和文本生成
- Google 或米醋的图像模型，用于生成分镜画面
- 火山方舟或 Atlas Cloud，用于 Seedance 视频生成
- 单条视频预算上限、视频清晰度及是否生成声音

配置完成后，打开一条包含视频的 X / Twitter 帖子，点击扩展图标即可开始收藏。

## 数据、隐私与安全

Style Lens 的设计原则是：能够留在本地的数据尽量留在本地，需要调用模型时明确交给用户选择的服务。

- API Key 保存在浏览器的 `chrome.storage.local` 中，不会写入代码，也不会进入备份文件。
- 收藏、设置、报告、风格分组和风格卡等结构化数据保存在浏览器本地。
- 生成的图片、视频和关键帧保存在本地 IndexedDB 中。
- 视频关键帧扫描和截取在浏览器本地执行，不消耗模型额度。
- 只有当你主动发起分析或生成任务时，相关视频、图片、帖子文字和提示词才会发送给所选模型服务商。
- 恢复备份采用合并方式，不覆盖或删除当前已有数据。
- 备份可能包含你的收藏、生成图片和视频，请像保管其他创作素材一样妥善保管。

使用前请自行阅读模型服务商的隐私政策、内容政策、数据保留规则和计费说明。

## 备份与迁移

审美库首页提供“备份”和“恢复”功能。备份文件包括：

- 收藏与拆解结果
- 喜欢点、风格分组和风格卡
- 分镜方案与主体设定
- 已生成的分镜画面和视频
- 已提取的关键帧
- 非敏感设置

API Key 永远不会进入备份。换电脑或重装浏览器后，恢复数据仍需重新填写 Key。

| `backup.js` | 本地数据、IndexedDB 素材的备份与合并恢复 |

## 开发与调试

项目不依赖框架和打包器，所有代码都可以直接由 Chrome 加载。

修改文件后：

1. 回到 `chrome://extensions/`。
2. 点击 Style Lens 卡片上的“重新加载”。
3. 刷新正在测试的 X / Twitter 页面或重新打开扩展页面。
4. 在扩展的 Service Worker、侧边栏或审美库页面查看控制台输出。

提交前建议验证：

- 扩展能够正常加载，没有 Manifest 错误。
- 设置页能够保存并检测所选服务的 Key。
- 侧边栏能识别 X / Twitter 视频帖和非视频页面。
- 收藏、逐镜拆解、失败重试与浏览器通知符合预期。
- 审美库、风格分组、风格卡和分镜方案可以正常打开。
- 备份与恢复不会覆盖已有数据，备份中不包含 API Key。
- 没有将真实密钥、用户收藏、生成素材或日志提交到仓库。

## 常见问题

### 一定要配置所有服务吗？

不需要。选择一体化方案时，一个 Atlas Cloud Key 可以覆盖主要流程。只有在自定义方案下，才需要为不同任务分别配置服务。

### 收藏风格和完整拆解有什么区别？

“收藏风格”更快，重点提取整体视觉语言和可复用提示词；“完整拆解”还会分析逐镜头结构，适合查看关键帧、研究剪辑和继续生成分镜。

### 关键帧提取会产生模型费用吗？

不会。视频扫描、切点校准和关键帧截取在浏览器本地完成。

### 为什么生成费用只是估算？

模型价格、计费单位、地区和账号折扣可能变化，扩展只能依据当前配置与公开单价提供参考，最终以服务商账单为准。

### 数据会上传给插件开发者吗？

代码中没有自建的用户数据后台。模型任务会把必要内容发送给你主动选择的模型服务商；请依据对应服务商政策决定是否使用。

### 能直接发布到 Chrome Web Store 吗？

当前仓库提供开发者模式加载和 Release 压缩包，尚未提供 Chrome Web Store 安装链接。

## 使用边界

Style Lens 的目标是帮助创作者学习风格方法，而不是复制他人的具体内容。请尊重原作者、平台规则、版权与模型服务商条款，不要将他人的作品、角色、肖像或提示词直接搬运用于未经授权的商业用途。

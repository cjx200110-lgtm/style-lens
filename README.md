# Style Lens（风格拆解）

把 X / Twitter 上值得收藏的 AI 视频，变成可检索、可复用、可继续创作的个人审美库。

Style Lens 是一个基于 Chrome Manifest V3 的浏览器扩展。打开一条视频帖后，它可以调用你选择的多模态模型，分析视频的视觉风格、镜头、节奏、声音与提示词；收藏积累后，还能生成审美报告、整理风格卡，并围绕新主题继续设计分镜、生成画面和视频。

> 当前版本：`0.19.0`。项目界面以中文为主，适合 AI 视频创作者、导演、设计师和视觉灵感收藏者。

## 主要能力

- **一键收藏与拆解**：在 X / Twitter 视频帖侧边栏中收藏风格，或进行包含逐镜头信息的完整拆解。
- **个人审美库**：按媒介质感、色彩、光影、景别、运镜、节奏、题材等维度组织收藏。
- **提示词与风格配方**：输出中英文提示词，便于在 Sora、Veo、Kling、即梦等创作工具中参考使用。
- **关键帧与高还原分镜**：在本地扫描视频、提取镜头关键帧，导出关键帧、分镜提示词和使用说明。
- **审美报告与风格分组**：根据收藏及手动偏好生成审美报告，自动分组并提炼可长期复用的风格卡。
- **从灵感到成片**：输入新主题生成分镜方案，生成或修改分镜画面，并通过 Seedance 等模型逐镜或整片生成视频。
- **本地备份与恢复**：将收藏、分镜、风格卡、图片、视频和关键帧打包备份；备份不会包含 API Key。

## 支持的模型服务

扩展允许按任务选择不同服务，实际可用模型以各服务账号权限为准：

- Atlas Cloud：视频拆解、分镜、生图与视频生成的一体化方案
- Google Gemini：视频理解与图像生成
- 米醋 API：Gemini 兼容接入
- 阿里云百炼 / 通义千问：多模态视频分析
- 火山方舟 / Seedance：逐镜与整片视频生成

模型调用会产生第三方服务费用。扩展提供预算上限和部分费用估算，但最终账单以服务商为准。

## 安装

本项目不需要构建，可以直接以“已解压的扩展程序”加载：

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本仓库目录。
5. 打开扩展设置页，选择服务方案并填写相应 API Key。
6. 打开一条 X / Twitter 视频帖，点击扩展图标开始使用。

要求 Chrome 114 或更高版本。

## 使用流程

```text
打开视频帖 → 收藏风格 / 完整拆解 → 补充“喜欢点”
          → 审美报告 / 风格分组 / 风格卡
          → 输入新主题 → 分镜方案 → 画面 → 视频 → 导出
```

## 数据与隐私

- API Key 保存在浏览器的 `chrome.storage.local` 中，不会进入扩展导出的备份文件。
- 收藏、设置等结构化数据保存在浏览器本地；生成的图片、视频和关键帧使用本地 IndexedDB 保存。
- 当你主动发起分析或生成任务时，视频、图片、帖子文字和提示词会发送给你所选择的模型服务商。
- 使用前请阅读相应服务商的隐私政策、数据保留政策和计费规则。

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | Chrome 扩展清单、权限与入口 |
| `background.js` | 后台任务、帖子解析与分析队列 |
| `sidepanel.*` | 视频帖侧边栏入口 |
| `library.*` | 审美库、报告、风格卡、分镜与生成工作台 |
| `options.*` | 模型服务、API Key、预算和生成参数设置 |
| `ai.js` / `gemini.js` / `qwen.js` | 多模态分析与模型适配 |
| `imaging.js` / `video.js` | 图像与视频生成 |
| `frames.js` / `decode.js` | 视频解码、镜头扫描与关键帧提取 |
| `backup.js` | 本地数据备份与恢复 |

## 开发

代码使用原生 HTML、CSS 和 JavaScript ES Modules，不依赖打包器。修改文件后，在 `chrome://extensions/` 中点击扩展的“重新加载”即可验证。

建议提交前至少完成以下检查：

1. 能正常加载扩展且没有 Manifest 错误。
2. 设置页可以保存并检测所选服务的 Key。
3. 侧边栏能够识别 X / Twitter 视频帖。
4. 收藏、备份、恢复和删除流程符合预期。

## 使用边界

拆解出的提示词与风格信息仅用于学习和创作参考。请尊重原作者及平台规则，不要直接搬运他人作品用于商业用途。
